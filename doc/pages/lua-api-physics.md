## `physics`

Physics body of an entity.

| Function                                                                                                                                                       | Returns                                  | Description                                                                                                            |
|----------------------------------------------------------------------------------------------------------------------------------------------------------------|------------------------------------------|------------------------------------------------------------------------------------------------------------------------|
| `physics.impulse(entity_id: entity, fx: number, fy: number, [fz: number])`                                                                                     |                                          | Apply a linear impulse to the body; fz for a 3D body.                                                                  |
| `physics.get_velocity(entity_id: entity)`                                                                                                                      | `vx: number`, `vy: number`, `vz: number` | Linear velocity of the body (zeros without a body); vz for a 3D body.                                                  |
| `physics.set_velocity(entity_id: entity, vx: number, vy: number, [vz: number])`                                                                                |                                          | Set the linear velocity of the body; vz for a 3D body.                                                                 |
| `physics.set_transform(entity_id: entity, x: number, y: number, rotation_or_z: number, [rx: number], [ry: number], [rz: number])`                              |                                          | Move the body: x, y and its rotation (radians) in 2D; x, y, z and Euler angles rx, ry, rz in 3D.                       |
| `physics.set_gravity_scale(entity_id: entity, scale: number)`                                                                                                  |                                          | Scale the world gravity for this body (0 = none).                                                                      |
| `physics.raycast(x: number, y: number, dx: number, dy: number, distance: number, [mask: integer])`                                                             | `hit: table`                             | First body a 2D ray meets, sensors ignored: `{entity, x, y, nx, ny, distance}`, nil for none.                          |
| `physics.raycast_3d(x: number, y: number, z: number, dx: number, dy: number, dz: number, distance: number, [mask: integer])`                                   | `hit: table`                             | First body a 3D ray meets: `{entity, x, y, z, nx, ny, nz, distance}`, nil for none.                                    |
| `physics.circle_cast(x: number, y: number, radius: number, dx: number, dy: number, distance: number, [mask: integer])`                                         | `hit: table`                             | First body a disc meets moving along (dx, dy); the hit as for `raycast`.                                               |
| `physics.box_cast(x: number, y: number, half_width: number, half_height: number, rotation: number, dx: number, dy: number, distance: number, [mask: integer])` | `hit: table`                             | First body a box (half sizes, rotation in radians) meets moving along (dx, dy).                                        |
| `physics.sphere_cast(x: number, y: number, z: number, radius: number, dx: number, dy: number, dz: number, distance: number, [mask: integer])`                  | `hit: table`                             | First body a sphere meets moving along (dx, dy, dz); the hit as for `raycast_3d`.                                      |
| `physics.overlap_circle(x: number, y: number, radius: number, [mask: integer])`                                                                                | `entity_ids: table`                      | Entities whose bodies overlap a disc, sensors ignored, in a fixed order.                                               |
| `physics.overlap_box(x: number, y: number, half_width: number, half_height: number, rotation: number, [mask: integer])`                                        | `entity_ids: table`                      | Entities whose bodies overlap a box (half sizes, rotation in radians).                                                 |
| `physics.overlap_sphere(x: number, y: number, z: number, radius: number, [mask: integer])`                                                                     | `entity_ids: table`                      | Entities whose bodies overlap a sphere.                                                                                |
| `physics.set_joint_motor(entity_id: entity, speed: number, [enabled: boolean])`                                                                                |                                          | Drive the hinge or slider joint of the entity at a speed (radians or units per second); enabled false stops the motor. |
| `physics.get_joint_position(entity_id: entity)`                                                                                                                | `position: number`                       | Angle of the entity's hinge joint (radians) or position of its slider; 0 otherwise.                                    |
