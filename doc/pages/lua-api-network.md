## `net`

Multiplayer: the session and its lobby, the remote calls, the replicated entities, the lockstep inputs and the lag compensation.

| Function                                                                                                                                        | Returns                                 | Description                                                                                                                                                                    |
|-------------------------------------------------------------------------------------------------------------------------------------------------|-----------------------------------------|--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `net.host([port: integer])`                                                                                                                     | `ok: boolean`                           | Open a lobby as the host on a port (0 or none: one the system chooses); false when the server does not start.                                                                  |
| `net.join(address: string, port: integer)`                                                                                                      | `ok: boolean`                           | Join the lobby of a host; `on_lobby_changed` follows once joined, `on_disconnected` when refused or unreachable.                                                               |
| `net.leave()`                                                                                                                                   |                                         | Leave the session: the host closes it for every player.                                                                                                                        |
| `net.get_role()`                                                                                                                                | `role: string`                          | What this machine is: `offline`, `host` or `client`.                                                                                                                           |
| `net.get_state()`                                                                                                                               | `state: string`                         | Where the session stands: `idle`, `lobby` or `playing`.                                                                                                                        |
| `net.is_server()`                                                                                                                               | `server: boolean`                       | Whether this machine decides the game: the host, or a game played offline.                                                                                                     |
| `net.get_local_player()`                                                                                                                        | `player: integer`                       | Number of the local player (0 for the host and offline).                                                                                                                       |
| `net.get_port()`                                                                                                                                | `port: integer`                         | Port the host listens on, 0 when not hosting.                                                                                                                                  |
| `net.set_player_name(name: string)`                                                                                                             |                                         | Name of the local player in the lobby.                                                                                                                                         |
| `net.set_input_type(type: string)`                                                                                                              |                                         | How the local player plays (`keyboard_mouse`, `gamepad`, `touch`): without crossplay, the host refuses players not playing like it.                                            |
| `net.set_ready(ready: boolean)`                                                                                                                 |                                         | Tell the lobby whether the local player is ready.                                                                                                                              |
| `net.get_players()`                                                                                                                             | `players: table`                        | Players of the lobby or match, as `{id, name, ready, input, connected, meets_minimum}`.                                                                                        |
| `net.is_everyone_ready()`                                                                                                                       | `ready: boolean`                        | Whether every player of the lobby is ready.                                                                                                                                    |
| `net.start_match(scene: string, [seed: integer])`                                                                                               | `ok: boolean`, `error: string`          | Host: every machine loads the scene and plays it (a `seed` other than 0 replaces the scene's); else false and why (`not_ready`, `below_minimum`...).                           |
| `net.kick(player: integer)`                                                                                                                     |                                         | Host: remove a player from the session.                                                                                                                                        |
| `net.rpc_server(entity_id: entity, name: string, ...)`                                                                                          | `sent: boolean`                         | Run the function `name` of the entity's script (0: the scene script) on the server, with the arguments (nil, booleans, numbers, strings).                                      |
| `net.rpc_client(player: integer, entity_id: entity, name: string, ...)`                                                                         | `sent: boolean`                         | Run the function `name` of the entity's script on one player's machine.                                                                                                        |
| `net.rpc_all(entity_id: entity, name: string, ...)`                                                                                             | `sent: boolean`                         | Run the function `name` of the entity's script on every machine, this one included.                                                                                            |
| `net.rpc_server_unreliable(entity_id: entity, name: string, ...)`                                                                               | `sent: boolean`                         | As `rpc_server`, sent once: a late or lost call is dropped (inputs sent every tick).                                                                                           |
| `net.rpc_client_unreliable(player: integer, entity_id: entity, name: string, ...)`                                                              | `sent: boolean`                         | As `rpc_client`, sent once.                                                                                                                                                    |
| `net.rpc_all_unreliable(entity_id: entity, name: string, ...)`                                                                                  | `sent: boolean`                         | As `rpc_all`, sent once.                                                                                                                                                       |
| `net.get_sender()`                                                                                                                              | `player: integer`                       | Player who sent the remote call running now (the local player outside one).                                                                                                    |
| `net.uuid(entity_id: entity)`                                                                                                                   | `uuid: string`                          | UUID of an entity as text, the same on every machine: pass it in a call, `scene.find_by_uuid` finds the entity.                                                                |
| `net.set_owner(entity_id: entity, player: integer)`                                                                                             | `ok: boolean`                           | Host: give a replicated entity to a player, who predicts it or decides it.                                                                                                     |
| `net.get_owner(entity_id: entity)`                                                                                                              | `player: integer`                       | Player owning a replicated entity (0 for the host).                                                                                                                            |
| `net.has_authority(entity_id: entity)`                                                                                                          | `authority: boolean`                    | Whether this machine moves the entity: offline, an entity it decides or predicts, any entity without `Replicated`.                                                             |
| `net.set_viewpoint(player: integer, x: number, y: number, [z: number])`                                                                         |                                         | Host: a point of view of a player for the interest management, besides the entities it owns.                                                                                   |
| `net.clear_viewpoint(player: integer)`                                                                                                          |                                         | Host: remove the point of view of a player.                                                                                                                                    |
| `net.is_held(player: integer, action: string)`                                                                                                  | `held: boolean`                         | Lockstep: whether a player holds an action in the tick playing.                                                                                                                |
| `net.is_pressed(player: integer, action: string)`                                                                                               | `pressed: boolean`                      | Lockstep: whether a player pressed an action in the tick playing.                                                                                                              |
| `net.get_value(player: integer, action: string)`                                                                                                | `value: number`                         | Lockstep: reading of a player's axis or button action in the tick playing.                                                                                                     |
| `net.get_vector(player: integer, action: string)`                                                                                               | `x: number`, `y: number`                | Lockstep: reading of a player's vector action in the tick playing.                                                                                                             |
| `net.get_tick()`                                                                                                                                | `tick: integer`                         | Ticks the scene played since it started (the same on every machine of a lockstep match).                                                                                       |
| `net.rewind_raycast(player: integer, ox: number, oy: number, oz: number, dx: number, dy: number, dz: number, range: number, [ignored: entity])` | `entity_id: entity`, `distance: number` | Host: the nearest hit sphere (`Replicated` hit radius) a shot crosses, every sphere where the shooting player saw it; the entity and the distance, nil for a miss.             |
| `net.get_stats()`                                                                                                                               | `stats: table`                          | Figures of the session: `role`, `players`, `ping`, `loss`, `sent` and `received` (bytes per second), `entities`, `tick`, `stalled`, `rpc_sent`, `rpc_received`, `desync_tick`. |
