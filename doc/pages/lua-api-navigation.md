## `nav`

Navigation meshes of the 3D scenes: paths over the floors and the links, the agents walking them around each other.

| Function                                                                                                                     | Returns                               | Description                                                                                                                                                                                                                                                                                                                  |
|------------------------------------------------------------------------------------------------------------------------------|---------------------------------------|------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `nav.find_path(entity_id: entity, from_x: number, from_y: number, from_z: number, to_x: number, to_y: number, to_z: number)` | `points: table`                       | Shortest path on the `NavMeshVolume` of an entity between two world points (each moved onto the mesh), links included: the corners as `{x1, y1, z1, x2, y2, z2, ...}`, start and goal included; nothing when a point is off the mesh or no path joins them. On a mesh of walk areas the points are (x, y) of the plane, z 0. |
| `nav.get_closest_point(entity_id: entity, x: number, y: number, z: number)`                                                  | `x: number`, `y: number`, `z: number` | Point of the navigation mesh of a `NavMeshVolume` nearest to a world point, within 2 units; nothing when the mesh is farther.                                                                                                                                                                                                |
| `nav.bake(entity_id: entity)`                                                                                                | `done: boolean`                       | Bake the navigation mesh of a `NavMeshVolume` again from the static geometry inside its box (a level built at run time); false when no floor was found, the previous mesh is then kept.                                                                                                                                      |
| `nav.go_to(entity_id: entity, x: number, y: number, z: number)`                                                              | `sent: boolean`                       | Send a `NavAgent` to a world point: the path is found at the next tick and walked around the walls and the other agents; false when the entity has no agent.                                                                                                                                                                 |
| `nav.stop(entity_id: entity)`                                                                                                |                                       | Stop a `NavAgent` where it stands.                                                                                                                                                                                                                                                                                           |
| `nav.is_moving(entity_id: entity)`                                                                                           | `moving: boolean`                     | Whether a `NavAgent` still has a path to walk, or a goal waiting for its path.                                                                                                                                                                                                                                               |
| `nav.get_target(entity_id: entity)`                                                                                          | `x: number`, `y: number`, `z: number` | World point a walking `NavAgent` goes to; nothing when it stands.                                                                                                                                                                                                                                                            |
| `nav.set_speed(entity_id: entity, speed: number)`                                                                            |                                       | Highest speed of a `NavAgent`, in world units per second.                                                                                                                                                                                                                                                                    |
