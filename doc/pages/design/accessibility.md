# Accessibility {#page-design-accessibility}

[TOC]

Every game made with Owl can be played by more people, with settings the player controls. Planned for v0.6.0, summarised in the [Roadmap](../roadmap.md).

## Plan

| Item               | Plan                                                                            |
|--------------------|---------------------------------------------------------------------------------|
| UI scale           | Scales the HUD and menus                                                        |
| Colour-blind modes | Through the post-processing LUT                                                 |
| Subtitles          | Dialogues and key sounds                                                        |
| Input remapping    | Planned in the gamepad improvements ([Windowing and input](windowing-input.md)) |
| Reduced motion     | Toggle for screen shake and motion effects                                      |
| Readable fonts     | Legible fonts and sizes by default                                              |
