## `voxel`

Blocks of a `VoxelWorld` and the aim of a `VoxelPlayer`; its edits call `on_block_broken` and `on_block_placed`.

| Function                                                                                 | Returns                                                                                                 | Description                                                                                                                                                                                                                                     |
|------------------------------------------------------------------------------------------|---------------------------------------------------------------------------------------------------------|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `voxel.get_block(entity_id: entity, x: integer, y: integer, z: integer)`                 | `block: integer`                                                                                        | Block id at a block position of the `VoxelWorld` of an entity (0 is air, also where no chunk is loaded).                                                                                                                                        |
| `voxel.set_block(entity_id: entity, x: integer, y: integer, z: integer, block: integer)` | `done: boolean`                                                                                         | Write a block id (0 breaks the block) at a block position and re-mesh around it; false when the entity has no voxel world, the id is not one of its blocks or, in a procedural world, the chunk is not streamed in. The edit is kept by a save. |
| `voxel.get_block_name(entity_id: entity, block: integer)`                                | `name: string`                                                                                          | Name of a block id of the palette of a voxel world; nothing for air or an unknown id.                                                                                                                                                           |
| `voxel.find_block(entity_id: entity, name: string)`                                      | `block: integer`                                                                                        | Block id of a name of the palette of a voxel world (0 when it has none).                                                                                                                                                                        |
| `voxel.get_target(entity_id: entity)`                                                    | `x: integer`, `y: integer`, `z: integer`, `normal_x: integer`, `normal_y: integer`, `normal_z: integer` | Block a `VoxelPlayer` aims at, within its reach, and the normal of the face it looks at (a block is placed at the position plus the normal); nothing when it aims at no block.                                                                  |
| `voxel.get_place_block(entity_id: entity)`                                               | `block: integer`                                                                                        | Block id a `VoxelPlayer` places; nothing when the entity has no voxel player.                                                                                                                                                                   |
| `voxel.set_place_block(entity_id: entity, block: integer)`                               | `done: boolean`                                                                                         | Choose the block id a `VoxelPlayer` places (a hotbar slot); false when the entity has no voxel player or the id is not a block.                                                                                                                 |
