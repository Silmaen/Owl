# Roadmap at a glance

Owl is the engine that mixes rendering styles (2D, raycast, voxel, isometric, 3D) in one game.

| Version | Date                | Status      | Theme                                                                    |
|---------|---------------------|-------------|--------------------------------------------------------------------------|
| 1.0.0   | Expected 2028-04-01 | Planned     | Stable: API frozen, SDK, two showcase games, Linux + Windows + Web       |
| 0.10.0  | Expected 2028-02-15 | Planned     | Opening & platforms: modding, Web backend, API freeze, release candidate |
| 0.9.0   | Expected 2027-12-15 | Planned     | Deterministic simulation, replay, rewind, networking                     |
| 0.8.0   | Expected 2027-10-15 | Planned     | Gameplay systems: AI, 3D physics, audio, narrative                       |
| 0.7.0   | Expected 2027-08-15 | Planned     | Content & visual scripting: asset cook, animation, PCG graphs            |
| 0.6.0   | Expected 2027-06-15 | Planned     | 3D core: meshes, PBR, shadows, render graph                              |
| 0.5.0   | Expected 2027-04-15 | Planned     | 2D complete: lighting, HUD, 2D physics, Owl Nest visual overhaul         |
| 0.4.0   | Expected 2027-02-28 | Planned     | Isometric renderer, MCP server in Owl Nest, gamepad                      |
| 0.3.0   | Expected 2027-01-15 | In progress | Foundations: bugs, safety nets, Owl RHI, Conan, iteration tooling        |
| 0.2.1   | Released 2026-06-27 | Released    | Voxel engine                                                             |
| 0.2.0   | Released 2026-06-02 | Released    | Renderer stack, raycasting, tilemaps, scene transitions                  |
| 0.1.1   | Released 2026-04-30 | Released    | Multi-document editor, code / node-graph / animation editors             |
| 0.1.0   | Released 2026-04-16 | Released    | Lua scripting, in-game UI, saves, packaged runner, prefabs, undo         |
| 0.0.3   | Released 2026-04-09 | Released    | Sound, sprites, meshes, scene hierarchy, asset packing                   |
| 0.0.2   | Released 2026-03-03 | Released    | Slang shaders, backgrounds, pause / step, scene jumps                    |
| 0.0.1   | Released 2025-02-06 | Released    | First release: minimal engine running scenes                             |

Dates are indicative: exit criteria take precedence. Details per version and item:
